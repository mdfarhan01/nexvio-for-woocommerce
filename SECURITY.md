# Security Policy

## Supported versions

Only the latest released version of Nexvio for WooCommerce receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.
Send a private report to **security@your-domain.com** (replace with your real address) with:

- the plugin version and your WordPress / WooCommerce versions
- steps to reproduce and the impact you see

You will get a reply within 5 working days. Confirmed issues are fixed in a new release and
marked as a security release in the changelog.
